# Compliance and Security Notes — Node.js Edition

This Node.js package includes session-backed CSRF protection, strict administrator allowlisting, password hashing, SQLite-backed sessions, rate limits on public submissions and admin login, request body limits, server-side validation, Helmet security headers, private review moderation, and separate display consent before a review can be published.

The website's policy pages are retained as company-provided draft content. Legal suitability has not been independently certified; have counsel review the policies for the company's actual operating jurisdictions and practices.

Local implementation checks do not replace production security review, HTTPS verification, dependency maintenance, backup testing, or real SMTP delivery tests.
